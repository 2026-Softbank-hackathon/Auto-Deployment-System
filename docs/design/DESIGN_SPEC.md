# camellia Design Spec — 「코로의 대모험」 1안

이 문서는 `mockups/` 폴더의 시안을 실제 React + TypeScript + Vite 프론트엔드에 옮기기 위한 기준입니다.

> `mockups/*.dc.html` 파일은 디자인 툴 전용 형식입니다 (`<x-dc>`, `<helmet>`, `{{ }}` 등).
> **코드를 그대로 복사하지 말고, 화면 구성·색·간격·문구를 보는 시각 참고 자료로만 사용하세요.**
> 브라우저에서 열면 대부분 정상적으로 보입니다.

---

## 1. 컨셉 한 줄

배포 버튼을 한 번 누르면, 구슬 캐릭터 "코로"가 연쇄장치를 굴러 지나가 결과 화면으로 튀어나온다.
복잡한 배포 과정은 존재하지만, 사용자가 하는 일은 **버튼 한 번**뿐이다. (태그라인: One Action, Infinite Clouds)

## 2. 디자인 원칙

1. **한 번 밀면 굴러간다**: 주요 액션은 아래로 눌리는 "키캡" 버튼.
2. **기계는 보이되 조용히**: 레일(선)이 구조를 만들고, 평소에는 움직이지 않는다.
3. **코로는 감정, UI는 사실**: 텍스트는 실제 백엔드 정보만. **가짜 퍼센트, 가짜 예상 시간 금지.**
4. 흐린 그림자·유리 효과·네온 그라데이션 금지. 딱딱한 바닥 그림자만 사용.

## 3. 디자인 토큰 (현재 시안 기준)

```css
:root {
  /* surface */
  --paper: #FAF8F3;          /* 페이지 배경 */
  --paper-side: #F5F2EB;     /* 사이드바 */
  --paper-sunken: #F1ECE2;   /* 드롭존, 로그, 주소 입력 영역 */
  --surface: #FFFFFF;        /* 카드 */
  --line: #D9CDB8;           /* 테두리, 비활성 레일, 버튼 그림자 */

  /* text */
  --ink: #2A2622;            /* 본문, 어두운 키캡 */
  --ink-deep: #0F0D0B;       /* 키캡 바닥 */
  --ink-soft: #6B6258;       /* 보조 텍스트 */

  /* brand & rail */
  --koro: #3563E9;           /* 코로, 진행 중, 브랜드 */
  --koro-text: #2F55C8;      /* 링크, 진행 중 텍스트 */
  --brass: #B8862E;          /* 완료된 레일, 링크 밑줄 */
  --brass-deep: #8A6420;

  /* status */
  --moss: #3F8F5A;  --moss-text: #2F7347;  --moss-on-dark: #6DBB85;   /* 성공 */
  --brick: #C2553A; --brick-text: #A9432B; --brick-on-dark: #E2795C;  /* 실패 */
  --pebble: #A39A8E;                                                   /* 대기 */

  /* shape */
  --radius-key: 14px; --radius-card: 12px; --radius-input: 10px; --radius-tape: 4px;
  --border: 1.5px solid var(--line);
  --shadow-rest: 0 3px 0 var(--line);
  --shadow-lift: 0 5px 0 var(--line);
  --shadow-press: 0 1px 0 var(--line);

  /* motion */
  --dur-tap: 80ms; --dur-quick: 160ms; --dur-roll: 240ms; --dur-scene: 600ms;
  --ease-roll: cubic-bezier(.5, 0, .2, 1);
}
```

배경: `--paper` 위에 24px 격자선 (`rgba(217,205,184,0.2)`).

> 색 방향은 아직 확정 전입니다. 「밝은 버전 C」(흰 바탕 + 코로 블루 키캡 + 옅은 알약형 상태 라벨)로 바뀔 수 있으므로 **색은 반드시 토큰으로만 참조**하세요.

## 4. 타이포그래피

| 용도 | 폰트 | 비고 |
|---|---|---|
| 제목, 키캡 버튼 | Jua | 임시. Pretendard Bold로 바뀔 수 있음 |
| 본문, UI | Noto Sans KR 400/500/700 | 본문 16px, 행간 1.7 |
| 로그, URL, 해시, 라벨 테이프 | JetBrains Mono 400/600 | 라벨 테이프는 12px, 자간 0.08em, 대문자 |

폰트는 가능하면 로컬 번들로 포함 (데모 현장 네트워크 대비).

## 5. 공통 컴포넌트

| 컴포넌트 | 설명 |
|---|---|
| `Rail` | 가로/세로 선 + 정거장(stop). 완료 구간은 `--brass`, 미완료는 `--line`. 네비게이션, 파이프라인, 타임라인에 공통 사용 |
| `Marble` | 상태 구슬. 위치가 곧 상태. 진행 중 `--koro`, 성공 `--moss`, 실패 `--brick`(레일 아래로 떨어진 위치), 대기 `--pebble` |
| `StatusTape` | 어두운 라벨 테이프 + 색 점 + 텍스트 (READY / DEPLOYING / LIVE / FAILED). **색만으로 상태 전달 금지, 항상 텍스트 포함** |
| `Keycap` | Primary: `--ink` 배경, 바닥 그림자 4~6px, 누르면 translateY 3px. Secondary: 흰 배경 + 테두리 + 그림자 3px. Destructive(되돌리기): 벽돌색 테두리, **길게 누르기(800ms)로만 실행** |
| `DeployKeycap` | 배포 버튼 전용. 왼쪽 원형 구멍에 코로가 살짝 보임. 비활성 시 회색 + 코로 눈 감음 |
| `GadgetIcon` | 단계 아이콘. 소스 업로드=출발대, AI 분석=도미노, 배포=깔때기, 검증=저울, 완료=컵 |
| `Koro` | 파란 원 + 눈. 표정: 보통 / 즐거움 / 졸림 / 당황. 등장 위치는 배포 버튼, 배포 중, 성공, 실패, 빈 상태로 한정 |
| `SoundToggle` | 헤더 오른쪽. SOUND ON/OFF |

## 6. 화면 매핑 (mockups 파일 ↔ 기존 화면)

| 파일 | 기존 화면 | 핵심 변경 |
|---|---|---|
| 01-dashboard-empty | 대시보드 (배포 내역 없음) | 빈 레일 + 졸고 있는 코로 일러스트, 「간단 배포로 이동」 키캡 |
| 02-upload-empty | 간단 배포 (파일 선택 전) | 상단에 소스→AI 분석→배포→검증→완료 레일, 드롭존, 비활성 배포 키캡 |
| 03-upload-ready | 간단 배포 (파일 선택 후) | 선택된 ZIP 표시, 배포 키캡 활성화 |
| 04-deploy-running | 배포 진행 (신규) | 단계 칩 + 연쇄장치 장면 + 작업 노트 한 줄. 애니메이션은 별도 작업 |
| 05-dashboard-list | 대시보드 (내역 있음) | 배포 1건 = 1행, 미니 레일로 진행 상태 표시 |
| 06-deploy-success | 배포 완료 (신규) | 코로가 결과 카드 위에 착지, 공개 주소, 단계별 소요 시간 |
| 07-deploy-failed | 배포 실패 (신규) | 멈춘 단계 표시, 원인, 로그 발췌, 다시 배포 / 되돌리기 |

기존에 있는 브랜드(camellia v0.4.0, 태그라인), 메뉴(대시보드, 간단 배포!), 주요 문구는 유지.

## 7. 백엔드 상태와의 연결

- 표시 가능한 단계: 소스 업로드 → AI 분석 → 배포 → 검증.
- 백엔드가 세부 단계를 주지 않으면 "배포 중" + 실제 경과 시간만 표시.
- 단계별 소요 시간, 실패 원인, 로그, AI가 정한 배포 방식(유형, 빌드 명령, 포트)은 **백엔드가 실제로 주는 값만** 표시. 없으면 해당 영역을 숨김.
- 실패 화면의 "AI 제안" 카드와 "이전 버전으로 되돌리기"는 백엔드 지원 여부 확인 후 구현.

## 8. 접근성

- 텍스트 대비 WCAG AA 이상.
- 버튼은 실제 `<button>` / `<a>`. 아이콘만 있는 버튼은 `aria-label`.
- 배포 진행 상태와 결과는 `aria-live="polite"`.
- `prefers-reduced-motion` 시 모든 이동·튕김 모션을 즉시 상태 변화로 대체.
