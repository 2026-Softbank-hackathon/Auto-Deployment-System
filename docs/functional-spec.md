# 0. 개요

**한 줄 정의: **로컬 웹앱을 올리면 AI 에이전트가 분석·수정하고, 온프레미스와 클라우드(AWS·GCP·Azure)에 운영 수준으로 원클릭 배포하는 시스템

**시스템 구성**

- 인터페이스: CLI, 웹 대시보드, AI 에이전트, CI 연동 → 모두 같은 API 사용

- 컨트롤 플레인: API 서버, 오케스트레이터, 분석기, IR, 플래너, 빌더, 프로바이더 어댑터, 상태 저장소

- 데이터 플레인: 온프레미스(Docker·k3s, 리눅스·맥·윈도우 VM), AWS, GCP, Azure

**용어**

- IR (앱 명세): 앱에 필요한 것을 클라우드 중립적으로 적은 설계도

- 대상 환경 (Target): 앱이 배포될 곳 (온프레미스 VM, AWS 계정 등)

- 배포 (Deployment): 특정 버전의 앱을 특정 대상 환경에 올리는 1회 작업

**핵심 사용자 흐름: **소스 업로드 → 스택 분석 → AI 코드 수정 제안·승인 → IR 생성 → 배포 환경 추천·선택 → 빌드 → 인프라 프로비저닝 → 배포 → 검증 → URL 제공 → 모니터링·롤백

**우선순위: **M(필수) / S(권장) / X(여유 있으면). 요구사항 문서에서 "해야 함"인 항목은 모두 M
