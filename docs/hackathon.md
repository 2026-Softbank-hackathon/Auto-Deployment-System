## 테마
One Action, Infinite Clouds. — 로컬 웹앱을 원터치로 배포. AI를 전적으로 활용해 Google Cloud·AWS 같은 하이퍼스케일러나 온프레미스(로컬)로 쉽게 배포하는 시스템. 코드를 자동으로 변경하며 인프라까지 구축.

고려 질문: 어디에 배포(Lambda/Cloud Functions, Fargate/Cloud Run, EC2/GCE)? 로컬·클라우드 데이터 관리? 클라우드·온프레미스 격차 극복? CI/CD 연동·DB 마이그레이션?

"간단한 배포" 예시(정답 아님): 광범위한 환경·규모 대응, SQLite → 적절한 RDS, 모니터링 도입·시각화, 배포 작업 로그, 롤백·블루그린·카나리, AI 비용 대비 효과, 여러 명 동시 안전 배포

제약: 클라우드·AI 자유(PC·VM을 온프레미스로 간주 권장), **배포 시스템 자체 품질로 평가**, 샘플 앱은 최소 기능
