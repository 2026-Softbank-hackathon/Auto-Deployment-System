- 관리형 DB 생성은 수 분 소요 → 사전 프로비저닝(DMO-01), 발표 시 사전 생성임을 명시
- 데모 3분 시나리오 초안: SQLite Todo 앱 소개 → deploy → AI 분석·diff → 로컬 배포 URL → 같은 명령으로 GCP 배포 URL(심사위원 폰 접속) → 에러 주입 → AI 진단 → 자동 롤백 → 대시보드 이력
