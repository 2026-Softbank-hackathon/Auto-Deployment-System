# Claude Code 시작 가이드

## 1. 준비
```bash
unzip deploy-system-handoff.zip && cd deploy-system
git init && git add . && git commit -m "docs: claude.ai 세션 핸드오프 (요구사항·기능명세·아키텍처·ERD v2)"
claude
```
Claude Code는 루트의 `CLAUDE.md`를 자동으로 읽는다.

## 2. 첫 메시지로 붙여 넣을 프롬프트
```
CLAUDE.md와 docs/ 전체(특히 open-items.md, decisions.md, poc-plan.md)를 읽고
지금 프로젝트 상황을 5줄로 요약해줘. 그다음 open-items.md의 A-1~A-7 문서 불일치를
하나씩 고칠 계획을 세우고, 내가 확인하면 수정해줘.
다이어그램은 docs/diagrams/mermaid/*.mmd를 고치고 tools/render_one.py로 다시 렌더링해.
스키마는 tools/schema_v2.py만 고치고 재생성해.
```

## 3. 이후 추천 순서
1. 문서 불일치 수정 (open-items A)
2. 팀 편성 후 미결정 사항 결정 (decisions.md "미결정") → ADR 기록
3. 모노레포 스캐폴딩 + control-plane docker-compose + postgres_schema_v2.sql 적용
4. PoC P-01~P-03 (D1) → poc-plan.md 순서

## 4. 도구 실행 조건
- `tools/schema_v2.py`: Python 3, 리포 루트에서 실행
- `tools/render_one.py`: `cd tools && npm i mermaid@11 && pip install playwright && playwright install chromium`, 한글 폰트(Noto Sans CJK KR) 필요
- `tools/gen.py`: 아키텍처 다이어그램 HTML 생성 (리포 루트에서 실행)
