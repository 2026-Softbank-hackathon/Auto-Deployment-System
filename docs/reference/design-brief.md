## 이 제품은 무엇인가
로컬에서 만든 웹앱을 올리면 AI가 분석·수정하고, 버튼 하나로 온프레미스와 AWS·GCP·Azure에 동시에 배포하는 배포 시스템의 관제 대시보드. (제품명 미정, 팀 camellia)
사용자: 인프라 전담자가 없는 개발팀의 백엔드 개발자. 해커톤 현장에서는 SoftBank 인프라·클라우드 엔지니어 심사위원이 5분 라이브 데모로 본다 (한·일 순차 통역).
가장 특징적인 시각 요소: 공항·철도의 **출발 안내판(departure board)**. 배포 1건이 "출발"이고, 대상 환경(온프레미스 / AWS / GCP / Azure)이 각각 한 줄씩 "승강장"이 되어 단계(분석 → 빌드 → 계획 → 적용 → 검증)와 상태가 행 단위로 바뀐다. 시스템 구조가 컨트롤 플레인(관제탑)과 데이터 플레인(각 환경)으로 나뉘어 있어서 이 은유가 구조와 그대로 맞는다.

## 레퍼런스 (이름으로)
1. **Vercel 배포 상세 페이지 (Deployment detail, 빌드 로그 화면)**
   닮을 것: 단계별 상태와 실시간 로그가 한 화면에 붙어 있는 밀도, 로그가 주인공인 구성.
   닮지 말 것: 흑백 Geist 룩, 마케팅 페이지 톤.
2. **Railway 2024 프로젝트 캔버스**
   닮을 것: 서비스·DB·환경을 공간에 배치해 관계를 한눈에 보여주는 방식 (MSA 배포 순서 표시에 사용).
   닮지 말 것: 어두운 보라 배경, 노드 글로우, 부드러운 카드 그림자.
3. **Teenage Engineering OP-1 field 매뉴얼 페이지**
   닮을 것: 엄격한 격자, 기계 패널 같은 라벨링, 강조색을 딱 한 군데만 쓰는 절제.
   닮지 말 것: 일러스트, 장난스러운 톤.

## 금지 (Forbidden)
- Inter, Roboto, Geist, Pretendard, 시스템 폰트
- 보라/인디고/파랑 그라데이션, 모든 그라데이션
- 크림+테라코타, 세리프 헤드라인 편집 무드
- 전체 화면 다크 모드 + 형광 초록 포인트 (로그 패널만 어둡게 허용)
- 3열 피처 카드, 중앙 정렬 히어로, 테스티모니얼 캐러셀
- 부드러운 드롭 섀도우, pill 버튼, glassmorphism
- Lucide 기본 아이콘, sparkle 아이콘, CTA 화살표, 클라우드 벤더 로고를 장식으로 쓰기
- AI를 반짝이·마법으로 표현하는 모든 것 (AI는 "판단한 근거"를 텍스트로 보여준다)
- "Elevate / Seamless / Powerful / 혁신적인 / 손쉽게" 류 카피

## 타이포
- 한글 본문·UI: **IBM Plex Sans KR** (400, 600)
- 일본어 병기: **IBM Plex Sans JP** (400, 600)
- 숫자·영문 디스플레이: **Archivo** (wdth 125, 700) — 경과 시간, 비율, 환경 코드에만
- 로그·IR·diff: **IBM Plex Mono** (400) — 코드와 로그에만. UI 라벨에는 쓰지 않는다
- 스케일(px): 72 / 32 / 24 / 18 / 15 / 13 / 12
  - 72: 현재 배포 상태 한 줄 (Archivo 700 + Plex Sans KR 600)
  - 24: 안내판의 환경 이름
  - 15: 본문·표 기본
  - 13: 로그, 보조 정보
  - 12: 일본어 병기, 타임스탬프
- 행간: 본문 1.5, 로그 1.45, 72px 줄 1.0
- 상태 단어는 한·일 병기: "검증 중 / 検証中", "승인 대기 / 承認待ち" (일본어는 12px, 한글 아래)

## 공간·형태
- base unit: 4px
- 허용 간격: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 72 (이 밖의 값 금지)
- radius: 패널·행·표 0px, 버튼·입력 2px. 그 외 값 금지
- border: 기본 1px --color-line. 현재 진행 중인 행만 왼쪽 4px --color-primary. 선택·포커스 2px --color-ink
- shadow: 없음. 위계는 선 두께와 면 색으로만
- 그리드: 12열, 거터 24px, 최대 폭 1440px, 좌우 여백 32px
  - 1–2열: 프로젝트·환경 목록 (세로 레일)
  - 3–9열: 출발 안내판 (환경별 행, 단계 칸, 상태, URL)
  - 10–12열: 실시간 로그 (--color-log-bg, 위에서부터 쌓임)
  - 최상단: 3–12열에 걸친 72px 현재 상태 줄 (왼쪽 정렬)
- 모든 텍스트는 왼쪽 정렬. 숫자 열만 오른쪽 정렬, tabular figures
- 1280px 이하: 로그 패널이 안내판 아래로 내려간다

## 이 화면의 "가장 시끄러운 것" 하나
화면 맨 위 한 줄, 72px:
"GCP 운영 — 검증 중  02:41"
(환경 이름과 상태는 Plex Sans KR 600, 경과 시간은 Archivo wdth 125 700)
그 아래 일본어 병기 "検証中" 12px. 나머지는 전부 13~24px.
동백 빨강은 이 줄의 앞쪽 4px 표시선과 "배포" 버튼, 딱 두 곳에만 나타난다.

## 실행 규칙
위 시스템을 정확히 따를 것. 목록에 없는 색·폰트·라운드·그림자를 새로 도입하지 말 것.
카피는 동사로 끝나는 짧은 문장: "배포", "승인", "롤백", "되돌렸어요: 에러율 4.2% 감지".
AI의 판단은 항상 근거와 함께 보여준다: "Cloud Run 추천 — 요청이 짧고 트래픽이 간헐적, 월 약 $6".
빈 상태와 실패 상태는 다음 행동을 알려준다: "대상 환경이 없어요. 환경 추가".
